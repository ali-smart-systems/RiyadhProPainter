# Riyadh Pro Painter

موقع Next.js جاهز كبداية قوية لمعلم دهانات بالرياض.

## قبل النشر
1. ضع صورك الحقيقية داخل `public/images/` وسمِّ الصورة الرئيسية `hero.jpg`.
2. تم إدخال رقم الاتصال والواتساب: +966 55 977 1963. أضف العنوان فقط إذا كان هناك عنوان نشاط حقيقي يستقبل العملاء.
3. إذا كان للنشاط عنوان فعلي، أضفه إلى LocalBusiness JSON-LD. لا تخترع عنواناً.
4. أضف محتوى وصور أعمال حقيقية مختلفة لصفحات العارض والياسمين والنرجس؛ لا تنسخ نفس النص فقط.
5. شغّل `npm install` ثم `npm run dev`.
6. ارفع المشروع إلى GitHub ثم اربطه بـ Netlify.
7. بعد ربط `riyadhpropainter.com`، أضف الموقع إلى Google Search Console وأرسل `/sitemap.xml` واطلب فهرسة الصفحات المهمة.
